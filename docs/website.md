# Website and external projects

- Landing page text lives in `site/i18n/*.json`, with every key in all four languages; the home page's scripts are the live phone mock (`site/static/live.js` with the vendored `adhan` library) and its progressive page interactions (`site/static/experience.js`), and its CSP allows same-origin scripts only, with inline scripts and styles blocked. See "Website" in `README.md`.
- Promo videos and the notification sounds are made in a separate repo, the promo media project (`video_marketing` in `external-projects.json`). Read its `readme` and `rules` before working there; this repo holds no promo scripts or videos, only the finished sounds it bundles. Separate projects are found through the git-ignored `external-projects.json`, one section each with its `folder`, `readme` and `rules`; copy `external-projects.example.json` if it's missing, and ask where a folder is if its path doesn't exist. Never write their paths into docs or code; name the section instead, and add a section to both files for a new project.
